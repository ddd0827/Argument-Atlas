ABOUT · 关于

论点地图

一个帮你看清「一段话究竟在论证什么」的小工具。它不替你下结论，而是把主张、证据、假设、反驳与追问摊开，让你自己判断。

它是怎么来的

这是一个学习式重写项目：研究开源项目 screenshot-to-code 的架构后，只借鉴它的三个抽象原则——

  • 结构化产物：让模型输出可校验的数据，而不是一段好看的文字。
  • 渐进反馈：用流式事件把等待变成可理解的过程。
  • 可替换的模型层：真实模型与离线 Mock 共用一套接口。

刻意没有照搬

  • 产品问题不同：它把截图变成代码，这里把文字变成论证结构。
  • 技术选择不同：FastAPI + 原生 ES Modules + SQLite，没有 React 构建链，也没有 WebSocket 中间件管线。
  • 数据模型与交互是重新设计的：主张 / 论据 / 假设 / 反驳 / 追问 / 谬误，加上「对单个节点追问」的对话层。

模型

默认接入 DeepSeek（OpenAI 兼容接口，可在 .env 中替换）。没有 Key 时自动进入完全离线的演示模式，所有交互都能体验。真实模式下，待拆解文本会发送到 DeepSeek 接口；演示模式不会联网。API Key 只保存在本地 .env，不会进入前端或日志。
